# 🌐 Unit Converter

A simple and interactive web-based unit converter built with JavaScript to practice DOM manipulation and user input handling.

---

## 🚀 Live Demo
https://aramizkingh.github.io/unit-converter/

---

## 🛠 Built With
- HTML  
- CSS  
- JavaScript  

---

## ✨ Features
- Convert kilometers to miles  
- Convert miles to kilometers  
- Input validation (positive numbers only)  
- Instant result display  
- Clean and simple UI  

---

## 🎯 Purpose
This project was built to practice:
- DOM manipulation  
- User input handling  
- Conditional logic in JavaScript

## 📖 How to Use
1. Enter a number  
2. Select conversion type  
3. Click "Convert"  
4. See result instantly
